연결 설정.

노션 DB와 연결해서
습관을 추적해 보세요

STEP 01
노션 Integration 만들기
notion.so/my-integrations 에서 새 Integration을 만드세요.
권한은 Read content와 Update content를 체크해주세요.

발급된 Internal Integration Token을 복사하세요.
STEP 02
노션 DB 템플릿 구성
노션에서 새 데이터베이스를 만들고, 아래 속성을 추가하세요.
이름(Name)은 기본으로 있어요.
속성 이름 타입 설명
이름title습관명 (기본 속성)
날짜date기록 날짜
완료checkbox오늘 완료 여부
카테고리select건강 / 공부 / 루틴 등
메모rich_text간단한 메모 (선택)
STEP 03
DB를 Integration과 연결
만든 데이터베이스 페이지에서 우상단 ··· 메뉴 → Connections → 방금 만든 Integration을 추가하세요.

그 다음, DB 페이지 URL에서 ID를 복사하세요.
URL 형식: notion.so/[workspace]/여기가 DB ID?v=...
STEP 04
CORS 프록시 설정 (필수)
브라우저에서 Notion API를 직접 호출하면 CORS 오류가 납니다.
무료 프록시 서버를 이용하거나, 본인의 서버를 사용하세요.

가장 간단한 방법 — Cloudflare Workers 무료 플랜으로 아래 코드를 배포하세요.
// Cloudflare Worker 코드
export default {
  async fetch(req) {
    const url = req.url.replace(self.location.origin, 'https://api.notion.com');
    const res = await fetch(url, {method:req.method, headers:req.headers, body:req.body});
    const headers = new Headers(res.headers);
    headers.set('Access-Control-Allow-Origin', '*');
    headers.set('Access-Control-Allow-Headers', '*');
    return new Response(res.body, {status:res.status, headers});
  }
}

🔒 개인정보 안전 — 입력한 토큰과 DB ID는
브라우저 localStorage에만 저장되며
어떤 서버에도 전송되지 않습니다.
