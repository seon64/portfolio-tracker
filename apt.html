노션 연동
Notion API를 통해 임장 기록을 자동으로 동기화합니다
연결 방법
노션 Internal Integration을 만들어 API 키와 데이터베이스 ID를 입력하면
임장 기록을 노션 DB에 자동으로 저장할 수 있습니다.
  1. 노션에서 notion.so/my-integrations 접속 → "New integration" 클릭 → 이름 입력 후 생성
  2. 생성된 Integration의 Internal Integration Secret 복사
  3. 노션에서 연동할 데이터베이스 페이지 열기 → 우측 상단 "···" → "Connect to" → 방금 만든 Integration 연결
  4. 데이터베이스 URL에서 ID 복사: notion.so/workspace/[여기가 DB ID]?v=...
  5. 아래에 API 키와 DB ID 입력 후 연결 테스트
⚠️ 노션 API는 CORS 정책으로 인해 브라우저에서 직접 호출이 제한됩니다.
로컬에서 사용하는 경우 CORS 허용 브라우저 확장 프로그램(예: CORS Unblock)을 설치하거나,
간단한 프록시 서버를 통해 연동하는 것을 권장합니다.
