연결 방법
노션 Integration을 만들고 API 키와 DB ID를 입력하세요.
  1. notion.so/my-integrations → "New integration" → 이름 입력 후 생성
  2. 생성된 Integration의 Internal Integration Secret 복사
  3. 연동할 노션 DB 열기 → 우측 상단 "···" → "Connect to" → Integration 연결
  4. DB URL에서 ID 복사: notion.so/workspace/[이 부분]?v=...
  5. 아래에 입력 후 저장 → 연결 테스트
