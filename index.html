설정값은 이 기기 localStorage에만 저장되며, 다른 사람에게 공유되지 않습니다.

📦 수동 백업 / 복원

Firebase 없이도 JSON 파일로 수동 백업·복원할 수 있습니다.

📖 Firebase 설정 방법 (5분)
1️⃣
Firebase 콘솔 접속
console.firebase.google.com 접속 → 구글 로그인 → 프로젝트 만들기
2️⃣
Firestore 활성화
왼쪽 메뉴 → Firestore Database → 데이터베이스 만들기 → 테스트 모드 선택
3️⃣
앱 등록 & 설정값 복사
프로젝트 설정(⚙️) → 앱 추가 → 웹(</>) → 앱 등록 → firebaseConfig 복사
4️⃣
위에 붙여넣기
이 페이지 위 📋 JSON 전체 붙여넣기 버튼 → 복사한 설정 붙여넣기 → 연결
⚠️ 보안 주의사항 Firestore → 규칙(Rules) 탭에서 30일 뒤 테스트 모드가 만료됩니다.
만료 전에 아래 규칙으로 교체하세요 (본인만 사용하는 개인 DB): 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
