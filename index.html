📤 내보내기 — 이 기기에서 데이터 저장

아래 버튼을 누르면 현재 모든 데이터(계좌·거래·종가)가 JSON 파일로 저장됩니다.
저장된 파일을 AirDrop 또는 iCloud Drive로 다른 기기에 전송하세요.

📱 전송 방법 AirDrop: 파일 앱 → 저장된 JSON → 공유 → AirDrop → 상대 기기 선택
iCloud: 파일 앱 → JSON을 iCloud Drive로 이동 → 다른 기기 파일 앱에서 열기
📥 가져오기 — 다른 기기 데이터 불러오기

다른 기기에서 내보낸 JSON 파일을 선택하면 데이터가 현재 기기에 덮어씌워집니다.
가져오기 전에 현재 데이터를 먼저 내보내두는 것을 권장합니다.

🔀 병합 가져오기 — 두 기기 데이터 합치기

덮어쓰지 않고 기존 데이터에 추가합니다. 중복 거래는 자동으로 제거됩니다.
